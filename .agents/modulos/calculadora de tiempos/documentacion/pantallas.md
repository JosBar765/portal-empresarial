# Calculadora de Tiempos — pantallas y acciones del mockup

Mockup: https://www.figma.com/design/b0CqDb0IHG3IpXRzGesFI5. Escritorio 1366×768 y celular 390×844.

## Calculadora (todos los usuarios con acceso)
| Acción | Pantalla (escritorio / celular) |
|---|---|
| Ver la calculadora vacía por primera vez | D7 / M7 |
| Elegir línea y producto | D6 / M6 |
| Escribir cantidad, colores y fecha | D1 / M1 · fecha: D13 / M11 |
| Activar extras (tamaño, costura, UV, urgente) y ver cómo suman | D8 / M8 |
| Ver el resultado y su desglose | D1 / M2 |
| Agregar piezas y ver la entrega del pedido | D2 / M3 |
| Editar o quitar una pieza | D9 / M9 · confirmar quitar: D10 / M15 |
| Copiar el resumen | D11 / M10 |
| Cantidad fuera de tabla y pedido urgente | D3 / M5 |
| Cargando, error, sin acceso, sin tabla publicada | D12 / M12 |

## Tabla de referencia (todos los usuarios con acceso)
| Acción | Pantalla |
|---|---|
| Consultar un producto | D4 / M4 |
| Buscar por nombre y por avisos | D4b |
| Búsqueda sin resultados | M13 |

## Administración (solo administrador; en celular se explica y lleva a Referencia: M14)
| Acción | Pantalla |
|---|---|
| Editar rangos y días (Cliente se calcula) | D5 |
| Errores al guardar | D5i |
| Extras: UV, moldes, colores, costura | D5b |
| Avisos por producto y generales | D5c |
| Etapas y líneas | D5d |
| Crear un producto | D5e |
| Publicar una versión nueva | D5f |
| Historial de versiones, ver cambios y reutilizar | D5g |
| Confirmaciones (eliminar rango, descartar, ocultar, descartar borrador) | D5h |
